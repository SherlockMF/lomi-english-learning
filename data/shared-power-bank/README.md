# 共享充电宝商业化词库

42 个工作表达，覆盖商户合作、点位拓展、租借流程、设备运营、收入分成及结算。中文对应本工作场景中的义项，定义和双语例句为本项目编写。

- `vocabulary.tsv`：七列文本格式，可整表复制到添加页；不需要更改列顺序。
- `shared-power-bank.vocabulary.json`：完整词库包，包含定义、双语例句与工作场景。在设置中选择「导入词库」进行合并，支持离线使用。

也可直接打开「添加」，点击「加入 42 个工作表达」，无需另行查询词典或准备文件。

JSON 中使用稳定 ID 与独立义项标识，可重复导入同一文件。新词加入优先学习，按每日固定额度推进；重复导入保留已有进度、已会及编辑。没有把工作短语等级冒充为经测评的 CEFR 义项等级。

## 语境容易混淆的表达

- **device placement agreement** 是本工作词库的「设备投放协议」。双方已经明确讨论哪台设备时，可以简称 **placement agreement**。首次提到文件时，写出 **device** 会更清楚。**equipment placement agreement** 也见于实际设备投放合同。校园用语 **student placement agreement** 指学生实习安排协议。 [设备投放合同示例](https://cokeflorida.com/wp-content/uploads/2024/02/Equipment-Placement-Agreement-for-non-FLOs-2-1-24.pdf) · [多伦多大学实习协议说明](https://www.viceprovoststudents.utoronto.ca/student-policies-guidelines/placements/)
- **charging station** 在本工作词库中是「充电宝租借站点」。需要明确区分充电宝和电动车时，可以写 **power bank rental station**。
- **site acquisition** 在本工作词库中是「点位拓展」，指联系并落实可安放设备的场所。在地产语境中，这个表达可指取得场地或收购地块，翻译时应看取得的是设备点位还是地产权益。

已添加旧版词条的用户，可以在学习卡片揭晓后点「纠正词条」，按自己的用语修改。保存后会用修正内容重新出题，原词条的学习进度继续保留。

术语选择参考行业官方公开页面：[Brick 合作介绍](https://www.brick.tech/en-it/partnership)、[怪兽充电公开年报](https://www.sec.gov/Archives/edgar/data/1834253/000141057825000928/em-20241231x20f.htm)。仅核对 powerbank rental、venue、network partner、rental revenue 等行业表达；本词库不沿用任何公司的价格、佣金比例或收益承诺。工作例句中的合同与财务词语用于语言练习。
