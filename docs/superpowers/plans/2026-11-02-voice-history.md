# 语音练习历史

目标：两种语音模式自动保存，刷新后可回看；语音消息可回听，用户确认后可单条删除或清空。

实现：沿用当前账号的 IndexedDB，新增独立的语音历史表。记录场景、时间、字幕、逐句纠错和课后反馈；语音消息保存音频 Blob。实时模式不新增录音。历史只读，不自动重连或调用 AI。当前版本仅本机保存，不进入现有 V3 学习备份或云同步，页面明确说明。

- [x] 存储：升级数据库，测试重开恢复、账号隔离、删除、空会话不保存。
- [x] 自动保存：接入实时字幕、消息音频与反馈，保存失败明确提示并提供重试。
- [x] 回看：模式选择页增加历史列表和详情，回听音频、复用加入复习，确认删除或清空。
- [x] 验证：运行相关 Vitest、lint、build，更新 README，审查变更。

验证结果：`npm test` 79 个文件、585 项测试通过；`npm run build` 通过；`npm run lint` 无错误，保留原有告警；`npx playwright test e2e/voice-history.spec.ts` 通过，覆盖原生 IndexedDB/Blob 刷新恢复、音频播放、取消删除、单次删除、清空后重开和手机宽度。新增自动保存行为由组件集成测试验证，未连接真实麦克风或收费 AI 服务。代码审查未发现重要问题。尚未部署。
